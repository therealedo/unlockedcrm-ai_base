2. Use the smallest safe read-only route.
3. Record direct load versus SPA navigation, viewport, settle time, tenant prerequisites, and visible state.
4. Do not cross setup, activation, submission, sending, export, upload, billing, or destructive boundaries.
5. Update this file, the audit, capability matrix, and source register together.

## Rule

`GATED` is a valid result. A blocked observation must not become a detailed mock specification unless a neutral product decision explicitly defines original behavior.
